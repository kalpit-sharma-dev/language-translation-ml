# Step-by-step implementation guideline

### Phase 0 — Prep (quick)

1. Create project repo and environment:

   * `git init` and create `README.md`
   * Create `conda` or `venv` environment file (list Python version, PyTorch, transformers, sentencepiece, sacrebleu, datasets, tokenizers, wandb or tensorboard)
2. Decide framework: **Hugging Face Transformers (README-ready)** or **Fairseq** (both are standard). I recommend Transformers for easier prototyping.

---

### Phase 1 — Get & inspect dataset

1. Download WMT English–German parallel corpus (pick a year, e.g., *WMT En-De*).
2. Inspect files: number of sentence pairs, file sizes, language noise.
3. Create splits: `train / dev / test` (e.g., use provided dev/test from WMT if available; otherwise split: 98% train / 1% dev / 1% test).
4. Save a small sample (2k pairs) for fast iteration.

---

### Phase 2 — Preprocessing & tokenization

1. Clean text: lowercase optionally, normalize punctuation, remove extremely long sentences ( > 250 tokens ) and empty lines.
2. Choose tokenizer:

   * Option A: **SentencePiece (unigram or BPE)** — build a joint vocabulary (shared source+target) or separate vocabs.
   * Option B: Byte-level BPE (like GPT-style) — robust but larger vocab.
3. Train tokenizer on combined English+German training text, vocabulary size `32k` or `50k`.
4. Convert corpus to token ids and store as TFRecords / binary / cache for fast training.

**Files to produce**: `tokenizer.model`, `vocab.json`, `train.ids`, `dev.ids`, `test.ids`.

---

### Phase 3 — Baseline model (Transformer)

1. Implement baseline Transformer (or use HF `MarianMT` / `T5` / `MBart` or a custom `Transformer`):

   * Typical baseline: 6 encoder layers, 6 decoder layers, model dim 512, ff dim 2048, 8 heads.
2. Loss: CrossEntropy with label smoothing (e.g., 0.1).
3. Optimizer: Adam with β=(0.9,0.98) and `warmup` + inverse sqrt learning rate schedule (or AdamW + linear warmup).
4. Batch size: depends on GPU. Example: effective batch tokens ≈ 4096–8192.
5. Train for N epochs (e.g., until convergence/early stopping on dev).
6. Logging: TensorBoard or Weights & Biases; save best checkpoint by dev sacreBLEU.

**Sample hyperparameters (baseline)**:

* vocab_size = 32000
* d_model = 512
* n_heads = 8
* d_ff = 2048
* encoder_layers = 6
* decoder_layers = 6
* dropout = 0.1
* label_smoothing = 0.1
* optimizer = Adam, lr = 5e-4 with warmup_steps = 4000
* batch tokens ≈ 4096
* epochs = 30 (monitor dev BLEU)

# Practical tips & common pitfalls

* Always use a validation set and save the best checkpoint by dev BLEU — don’t rely on training loss only.
* Keep consistent tokenization between training and inference; save tokenizer with model.
* Use sacreBLEU for reproducibility — it standardizes tokenization.
* Watch for length filtering: too aggressive removal of long sentences can bias results.
* If compute-limited: train for fewer epochs with larger learning rate and good checkpointing; consider fine-tuning a pretrained model (mBART/marian) for much better performance with less data.
* Log everything (hyperparameters, seed, commit hash) — reproducibility is critical.

# Quick starter code snippet (PyTorch - model init)

```python
# src/model.py (snippet)
import torch.nn as nn
from torch.nn import Transformer

class SimpleTransformerNMT(nn.Module):
    def __init__(self, vocab_size, d_model=512, nhead=8, num_encoder_layers=6, num_decoder_layers=6, dim_feedforward=2048, dropout=0.1):
        super().__init__()
        self.tok_embed = nn.Embedding(vocab_size, d_model)
        self.pos_encoder = PositionalEncoding(d_model, dropout)
        self.transformer = Transformer(d_model, nhead, num_encoder_layers, num_decoder_layers, dim_feedforward, dropout)
        self.generator = nn.Linear(d_model, vocab_size)

    def forward(self, src, tgt, src_mask, tgt_mask, src_key_padding_mask, tgt_key_padding_mask):
        src_emb = self.pos_encoder(self.tok_embed(src) * math.sqrt(self.tok_embed.embedding_dim))
        tgt_emb = self.pos_encoder(self.tok_embed(tgt) * math.sqrt(self.tok_embed.embedding_dim))
        out = self.transformer(src_emb, tgt_emb, src_mask=src_mask, tgt_mask=tgt_mask,
                               src_key_padding_mask=src_key_padding_mask, tgt_key_padding_mask=tgt_key_padding_mask)
        return self.generator(out)
```
